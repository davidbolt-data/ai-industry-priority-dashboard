# Where AI Is Actually Needed  
### According to AI Models Themselves

This project analyzes which industries most need artificial intelligence by comparing rankings from three AI models: **ChatGPT**, **Claude**, and **Gemini**.

By converting rankings into a weighted point system, the dashboard highlights both overall consensus and differences in how these models prioritize industries.

## Key Insights

- **Healthcare** ranks highest across all models, achieving a perfect score.
- **Supply Chain & Logistics** shows strong cross-model agreement.
- **Cybersecurity** appears only in Gemini’s rankings, suggesting a more technical focus.
- **Retail** ranks lowest overall, with minimal prioritization.

---

## Methodology

Each model ranked five industries. Rankings were converted into a weighted scoring system:

| Rank | Points |
|---:|---:|
| 1 | 5 |
| 2 | 4 |
| 3 | 3 |
| 4 | 2 |
| 5 | 1 |

Scores were then aggregated to create a comparative leaderboard across all models.
